# Efeitos sonoros

Arquivos de áudio usados pelo app:

| Arquivo           | Uso                              |
|-------------------|-----------------------------------|
| `card-flip-01.mp3` | Virar o card (escolhido aleatoriamente) |
| `card-flip-02.mp3` | Virar o card (escolhido aleatoriamente) |
| `correct.mp3`     | Resposta correta                  |
| `error.mp3`       | Resposta incorreta                |

O efeito de virar card alterna entre `card-flip-01` e `card-flip-02` de forma aleatória.
